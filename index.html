DATA + AI / 湖仓一体

快递物流智能数据治理与客服归因分析平台

2026.05 — 至今

技术栈Flink · Spark · Hadoop · Python · Java · K8s · Docker · Qwen3-8B · vLLM · SFT + GRPO · Markdown 上下文工程

业务背景
针对多源运单与客服数据的离线实时割裂、运单口径不统一、异常归因依赖人工及 ETL 维护成本高等问题，搭建存算分离湖仓一体实验平台，支撑运单画像、异常归因和客服 Agent 的可信数据调用。
方案选型
采用 Hudi 承接运单 CDC 高频更新、Iceberg 存储离线追加数据；由 Flink 实时入湖、Spark 完成离线回补，引入 Doris 加速热数据 OLAP 查询。组件基于 K8s 容器化部署，隔离 CPU/GPU 资源。
具体实现
利用大模型辅助生成数据清洗 SQL 和数据血缘；以 Markdown 结构化存储业务 SOP 与数据约束，动态加载上下文。搭建 SFT + GRPO 后训练流程，在奖励函数中引入数据一致性校验；通过 vLLM 部署推理服务，结合 Docker 沙箱与 Computer Use 完成湖仓查询和运单后台的多跳推理。
效果评估
基于本地采样运单数据集完成全链路评测，ETL 规则由人工编写转向 LLM 辅助生成。后训练使多跳工具调用的证据 EM 从 24% 提升至 51%，证据与答案联合 EM 从 13% 提升至 29%。
